# HackathonFinder.in

A directory of hackathons — find live, upcoming, and past events by city, mode, deadline, team size, and prize pool.

> Status: early setup. The site itself has not been built yet. Seed research lives outside this repo for now.

## Planned scope

- Browse hackathons by city (starting with Pune), mode (online / offline / hybrid), and date
- Status tracking: open, in progress, registration closed, completed
- Filters for team size, prize pool, organizer/college, and student eligibility
- Calendar view plus detailed event pages with registration links
- Submission form so organizers can list their own hackathons

## Getting started

Nothing to run yet. Clone the repo and watch this space:

```bash
git clone https://github.com/Rohit94r/HackathonFinder.in.git
cd HackathonFinder.in
```
